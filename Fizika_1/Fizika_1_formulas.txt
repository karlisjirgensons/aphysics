# Fizika I - formulu lapas pieraksts (kanoniskais saraksts)
#
# Šis ir VIENS avots tam, kādā formā formulu raksta stundu prezentācijās
# (SRP). Uzdevuma sadaļā "Formulas:" vispirms raksta formulu tādā formā,
# kāda tā ir formulu lapā, un tikai pēc tam - no tās izteikto formu, ko
# tiešām lieto aprēķinā. Piemēram:
#
#     Formulas:  λ = v · T        (formulu lapas forma)
#                T = λ/v          (izteiktā forma)
#
# Formāts vienā rindā:
#
#     lapas formas, atdalītas ar  ;   |   izteiktās formas, atdalītas ar  ;
#
# Pa kreisi no  |  ir visi pieraksti, kas formulu lapā tiešām ir - arī tie
# paši ar citu apzīmējumu (a = v²/r un a = v²/R; ceļš ir S, attālums - L).
# Pa labi - formas, kas lapā NAV un ko iegūst, izsakot lielumu; tādas drīkst
# lietot tikai kopā ar lapas formu.
#
# Formulas, kuru formulu lapā nav (definīcijas, mērvienību pārrēķini,
# ģeometrija, palīgsakarības), šeit neraksta - tad der jebkura forma.
#
# ## sāk sadaļu, # ir komentārs.
# Pārbauda:  .venv/Scripts/python.exe _tools/check_formulas.py
